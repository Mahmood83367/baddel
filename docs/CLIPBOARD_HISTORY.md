# Clipboard history (macOS)

An opt-in, local history of what you copy on macOS: text, images and files. It
is part of the macOS app from version 0.2.0. It is **off until you turn it on**.

## Using it

- Open **Clipboard History…** from the menu bar icon, or press **⌥⇧V**.
- Turn on **Keep clipboard history on this Mac**. From then on new copies are
  recorded; nothing copied earlier is.
- Search the list, select an entry and click **Copy** to put it back on the
  clipboard, then paste with ⌘V in the app you were using.
- **Delete** removes one entry. **Clear Recent…** removes everything that has
  not been kept as a file copy.

The correction shortcut is unchanged, and the two shortcuts are registered
separately: pressing one never triggers the other.

## What is stored, and where

Everything is stored under `~/Library/Application Support/Baddel/Clipboard`,
a folder created with owner-only permissions. Nothing is sent anywhere.

| Copy | What is kept |
|---|---|
| Text | The text, up to 256 KB per entry |
| Image | The PNG or TIFF data, up to 8 MB per entry and 64 MB in total |
| Files | **The paths only** — a reference to where each file is |

Up to 100 recent entries are kept; older ones are dropped, together with any
image data they held.

### File references and Keep File Copy

A file entry points at the original. If the original is moved or deleted, the
entry can no longer be copied back, and Baddel says so instead of pasting
something else.

**Keep File Copy…** is an explicit action that copies the files into Baddel's
folder. A kept entry no longer depends on the original — it still works after
the original is deleted — and it is not removed by **Clear Recent…**. Deleting
the entry deletes the kept copy. If an original is already missing, keeping a
copy fails with a message rather than recording a dangling reference.

## What is never recorded

Entries whose source marks them as concealed, transient or auto-generated
(`org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`). This
is how password managers mark secrets, and how Baddel marks its own paste
fallback, so neither ends up in the history.

Applications that do not set those markers are recorded like any other copy.
Treat the history as you would any file on your Mac that holds what you copied.

## How it works

`NSPasteboard` has no change notification, so while recording is on the app
checks the pasteboard's change counter twice a second and reads it only when
the counter moves. That is unrelated to keyboard input.

## Tested

Unit tests cover text and the "do not record" markers, restoring an image, and
a kept file copy surviving deletion of its original, both against a test double
and against **real macOS pasteboards** (uniquely named ones created for each
test, never the system clipboard). See [TESTING.md](TESTING.md).

## Not in this version

- Excluding specific apps.
- Search inside images (text recognition).
- Security-scoped bookmarks, which would let a file reference survive a move or
  rename; references are plain paths today.
- A choice of clipboard shortcut and of the limits above.
- Clipboard history on Windows and Linux.
