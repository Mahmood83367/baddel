Baddel __VERSION__

Baddel fixes Arabic or English text typed with the wrong keyboard layout.

This installer copies Baddel.app to your Applications folder and does nothing else. It runs no scripts, installs no background service, does not make Baddel open at login, and changes no permission. If Baddel is open, quit it first (menu bar icon → Quit Baddel), including a copy from an earlier preview. The installer will ask you to close it if it is still running.
