Baddel is installed

  1. Open it: Applications → Baddel. It appears as a keyboard icon in the menu bar, not in the Dock.
  2. Allow Accessibility: Baddel shows a window that takes you to System Settings → Privacy & Security → Accessibility. Turn Baddel on there. It needs this to fix text in other apps.
  3. Coming from an earlier preview? If Baddel is already switched on in that list but its window still says access is not granted, click Remove Old Entry… in Baddel's window, then allow it again. Delete any old copy of Baddel you kept outside Applications.
  4. Open at login (optional): menu bar icon → Settings → Open Baddel at login. Turn it off in the same place, or in System Settings → General → Login Items.

To uninstall: turn off Open Baddel at login, quit Baddel, and move Baddel from Applications to the Trash. The guide on the project page lists the settings files you can also remove.
